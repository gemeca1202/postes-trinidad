# Postes · Trinidad de las Huertas

Croquis del **Comité Vecinal del Fraccionamiento Trinidad de las Huertas** (Oaxaca de Juárez) para registrar los postes del alumbrado público, recibir reportes de vecinos y dar seguimiento a las reparaciones.

- **Vecinos:** ven el mapa y pueden reportar fallas sin clave.
- **Comité (admin):** con la clave del comité agrega, mueve y edita postes, revisa reportes y genera claves temporales.
- **Operadores:** con una clave temporal marcan los postes como reparados.

Los datos se guardan en una hoja de Google del comité (Apps Script). Base cartográfica: © colaboradores de OpenStreetMap.
